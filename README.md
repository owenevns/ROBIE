6 DOF NEMA-17 driven robot arm. cycloidal drive joints.
This project was done as a challenge to build a cycloidal drive jointed robot arm with 6 degrees of freedom. 
Using only Nema-17 motors and 3d printed parts it was difficult to achieve the tolerances needed. I inevitably had to also create live position feeback using AS5600 magnetic encoders to better track and correct all of the joint positions. 

Overall, the project is still a WIP and needs some more RND when it comes to making more gearboxes for the higher joints.
